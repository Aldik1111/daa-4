# Student checks

Run from the repository root with Python 3.12+ and JDK 17+:

- `python tests/student/check.py` runs the deterministic boundary, oracle and scale checks over the JSONL interface.
- Compile and run `SearchBenchmark.java` using the commands in [ANALYSIS.md](../../ANALYSIS.md) to reproduce the search comparison.

The case descriptions and actual results are recorded in the analysis.
